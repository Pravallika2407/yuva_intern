# Week 3 — Advanced Data Analysis and Visualization in Logistics

| Script | Purpose |
|---|---|
| `src/00_generate_dataset.py` | Generates the synthetic shipment dataset (`shipment_dataset.csv`, 2,000 records across 5 warehouses) used for the analysis. |
| `src/07_eda_visualization.py` | Computes summary statistics and correlations, and produces the 6 charts (distribution, boxplot, scatter, heatmap, bar, weekly trend) referenced in the Week 3 report. |

## Setup

```bash
pip install -r requirements.txt
python src/00_generate_dataset.py     # generates shipment_dataset.csv
python src/07_eda_visualization.py    # charts saved to week3_assets/
```

Report: `Week3_Advanced_Data_Analysis_Visualization_Report.docx` (submitted separately).
